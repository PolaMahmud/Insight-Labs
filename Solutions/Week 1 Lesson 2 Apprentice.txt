THE IDEA
--------
Total Streams is CARDINAL data (raw magnitudes) — sorting it works
perfectly. Popularity Tier is ORDINAL data (Bronze < Silver < Gold
< Platinum). Sorting the *text* only sorts it A→Z, which produces
the WRONG order: Bronze, Gold, Platinum, Silver (B, G, P, S).

WHAT TO DO
----------
1. Paste the code below into the Code Box and press ▶ Run.
2. In the Data Engine, CLICK the "Popularity Tier" column header
   once so it is flagged/highlighted (this is check #15).
   The grader re-runs automatically when you flag the column.

CODE (paste into the Code Box)
------------------------------
import pandas as pd

df = pd.read_csv("spotify_tracks.csv")

# --- CARDINAL: Total Streams sorts perfectly by magnitude ---
df = df.sort_values("Total Streams", ascending=False)
print("Top by Total Streams (Cardinal):")
print(df[["Song Title", "Total Streams"]].head())   # avoid tier names here

# --- ORDINAL TRAP: sorting the text tier only sorts A->Z ---
df = df.sort_values("Popularity Tier", ascending=True)
print("Popularity Tier sorted alphabetically (top 10):")
print(df["Popularity Tier"].head(10))

# Prove the alphabetical category order is Bronze, Gold, Platinum, Silver
print("Alphabetical order:", sorted(df["Popularity Tier"].unique()))
print("Alphabetical sorting breaks the ranking order!")

# Classify the two scales
print("Total Streams -> Cardinal")
print("Popularity Tier -> Ordinal")
