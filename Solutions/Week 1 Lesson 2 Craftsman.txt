THE IDEA
--------
Fix the broken ordinal scale by mapping each tier string to a strict
number so the computer understands the hierarchy:
    Bronze = 1, Silver = 2, Gold = 3, Platinum = 4
Then sorting on the new numeric column gives the honest 4-3-2-1 order.

WHAT TO DO
----------
Paste the code below into the Code Box and press ▶ Run.
No grid clicking is required — this tier is graded from the code
and its results.

KEY GOTCHA
----------
Use the EXACT column name "Popularity Tier". Map onto a NEW column
called "Tier Rank" (check #19 rewards the rename for mastery).

CODE (paste into the Code Box)
------------------------------
import pandas as pd

df = pd.read_csv("spotify_tracks.csv")

# Step 1: a dictionary that encodes the hierarchy
rank = {"Bronze": 1, "Silver": 2, "Gold": 3, "Platinum": 4}

# Step 2: map the text onto a new numeric column
df["Tier Rank"] = df["Popularity Tier"].map(rank)

# Step 3: confirm it is now numeric (int64), not object
print("New dtype:")
print(df["Tier Rank"].dtype)

# Step 4: sort by the SEMANTIC rank, highest tier first
df = df.sort_values("Tier Rank", ascending=False)
print("Top (Platinum = 4):")
print(df[["Popularity Tier", "Tier Rank"]].head())
print("Bottom (Bronze = 1):")
print(df[["Popularity Tier", "Tier Rank"]].tail())
